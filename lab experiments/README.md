# Compiler Design Lab Experiments

Individual source files for experiments 1–40 from the supplied CSA14 lab manual. Experiments 1–20 are C programs (`.c`); experiments 21–40 are Flex/Lex specifications (`.l`). Experiments 33 and 34 refer to experiments 32 and 31 in the manual, so their source files repeat those programs.

The files preserve the manual's code, including any compiler or runtime adjustments that may be needed for a modern toolchain.
