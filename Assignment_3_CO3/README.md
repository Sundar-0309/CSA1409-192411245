# Assignment 3 - Compiler Design CO3

This is an original, runnable implementation of syntax-directed translation for the CO3 assignment. It contains seven small compiler exercises and an integrated MiniLang translator.

## Run

```powershell
cd Assignment_3_CO3
python run_all.py
python -m unittest discover -s Tests -v
```

## Coverage

| Question | Implementation |
| --- | --- |
| Q1 | Synthesized expression attributes, annotated tree, value and height |
| Q2 | Inherited declaration types, symbol table and duplicate detection |
| Q3 | Dependency graphs, Kahn topological ordering and cycle detection |
| Q4 | Infix-to-postfix syntax-directed translation |
| Q5 | Parse-tree and compact AST construction |
| Q6 | Marker explanation and three-address-code generation |
| Q7 | MiniLang declarations, assignments, type checks, AST and TAC |

Every directory contains files used by the program or documentation; no placeholder folders are included.
