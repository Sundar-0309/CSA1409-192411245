# Submission summary

This repository contains an original Flex implementation of the ThreatRule lexical analyser for CSA1409 Assignment 1.

| Evidence | Location |
| --- | --- |
| Assignment report and scope | `Assignment_Document/` and `REPORT.md` |
| Scanner implementation | `src/threatrule.l` |
| Compiler and recognition diagrams | `Diagrams/` |
| Input sets | `Input_Files/` |
| Expected behaviour and generated results location | `Output_Files/` |
| Performance procedure | `Performance_Analysis/` and `Graphs/` |
| Test cases | `Test_Cases/` |
| Reproducible commands | `Makefile` and `scripts/` |

Before submission, run the test suite on a computer with current Flex and GCC, then save the resulting terminal output in `Output_Files` and measured timings in `Performance_Analysis/results.csv`.
